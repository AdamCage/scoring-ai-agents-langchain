# Стандарт объяснимости

7.5.1. Карточка решения обязана показать top-3 фактора, повышающих риск, и top-3 фактора, снижающих риск.

7.5.2. Запрещено приписывать модели признаки, которых нет в SHAP.

7.5.3. Цитаты политики должны совпадать с `citation` извлечённых документов.
